AMZ Store Core
==============
Version: 1.0.0
Requires: WordPress, WooCommerce

Install by copying this folder to wp-content/plugins/amzstore-core and activating it in Plugins.
It adds AMZ Store inventory/condition/fitment/supplier/price reference fields to WooCommerce products.
Shortcodes:
[amz_parts_search]
[amz_price_comparison]

Price references are manually maintained and are not live competitor prices. Vehicle registration lookup and supplier availability feeds require separate integrations.
