AMZ Store WordPress Theme
========================
Version: 1.0.0

Install by copying this folder to wp-content/themes/amzstore and activating it in Appearance > Themes.
WooCommerce is recommended for product catalogue, basket and checkout functionality.
Upload the official AMZ Store logo through WordPress Site Identity to replace the text logo.

See the project README.md and docs/LOCAL-SETUP.md for full setup instructions.
